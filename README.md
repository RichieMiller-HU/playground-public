# XL-FittLesz – weboldal újratervezési koncept

Statikus koncept (nincs build lépés): nyisd meg az `index.html`-t böngészőben.

- `index.html` – új főoldal (hero, óráink, órarend, edzőink, miért mi, árak, kapcsolat)
- `foglalas.html` – interaktív időpontfoglaló (4 lépéses, csoportos óra / fallabda / PT / wellness)
- `assets/chatbot.js` – jobb alsó "XL Asszisztens" demó chatbot (szkriptelt, foglalás / árak / nyitvatartás / próbaedzés)
- `AUDIT.md` – a jelenlegi oldal UI/UX auditja és a koncept indoklása a kliensnek
- `audit/` – képernyőképek a jelenlegi oldalról
- `BRIEF.md` – a design tokenek és a felhasznált valós tartalom

Minden foglalás és chat szimulált (localStorage / sessionStorage), nincs backend.
